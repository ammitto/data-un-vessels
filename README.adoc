= Ammitto UN 1718 vessel sanctions data

image:https://github.com/ammitto/data-un-vessels/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-un-vessels/actions/workflows/fetch.yml"]

This repository stores UN Security Council 1718 Committee vessel
designations as YAML for Ammitto. The committee was established pursuant
to resolution 1718 (2006), on North Korea; `processed/` holds one file per
vessel.

== Source

* Publisher: United Nations Security Council, Committee established pursuant to resolution 1718 (2006)
* Committee page: https://main.un.org/securitycouncil/en/sanctions/1718
* List page: https://main.un.org/securitycouncil/en/sanctions/1718/materials/1718-Designated-Vessels-List
* File downloaded (PDF): https://main.un.org/securitycouncil/sites/default/files/1718_designated_vessels_list_final.pdf

The committee page sets out the measures that apply to designated vessels,
such as port entry bans, de-flagging and asset freezes.

== Contents

`processed/` holds one file per vessel, named after its IMO number:
`processed/un-vessel-7303803.yaml` is IMO 7303803. A vessel listed without an
IMO number is named after the vessel name instead, such as
`processed/un-vessel-min-ning-de-you-078.yaml`.

`processed/_index.yaml` lists every file, with the time of the last fetch.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `id` | string | Identifier, such as `un-vessel-7303803`
| `entity_type` | string | Always `vessel`
| `names` | list | Names: `full_name`, and `is_primary` (true for the main name, false for other names)
| `imo_number` | string | IMO number, where listed
| `date_designated` | string | Designation date, `YYYY-MM-DD`
| `resolution` | string | Always `Resolution 1718 (2006)`, the committee's founding resolution, for every vessel
|===


`reference-docs/` holds a copy of the PDF list and an HTML version of it.

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/un-vessel-*.yaml").sort.each do |path|
  vessel = YAML.safe_load_file(path)
  name = vessel["names"].find { |n| n["is_primary"] }["full_name"]
  puts [vessel["imo_number"], name, vessel["date_designated"]].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/un-vessel-*.yaml")):
    with open(path, encoding="utf-8") as f:
        vessel = yaml.safe_load(f)
    name = next(n["full_name"] for n in vessel["names"] if n["is_primary"])
    print(vessel.get("imo_number", ""), name, vessel["date_designated"], sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/un_vessels.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 06:00 UTC and commits any change to `processed/`. It runs with
`--prune`, so a vessel the committee has removed is deleted here on the next
fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.4 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch un_vessels --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/un_vessels[`lib/ammitto/sources/un_vessels/`].
Report data or source-list issues in
https://github.com/ammitto/data-un-vessels/issues[this repository].
